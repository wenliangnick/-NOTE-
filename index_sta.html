離散型 Discrete

二項分布 (Binomial Distribution)

標準記號：$X \sim \text{Bin}(n, p)$

1. 直觀意義與應用場景

描述在 $n$ 次獨立且相同（i.i.d.）的伯努利試驗（Bernoulli Process）中，達成「成功」的總次數[cite: 90]。每次試驗僅有成功（機率 $p$）與失敗（機率 $q = 1 - p$）兩種互斥結果，且各次試驗互不影響（如放回抽樣）[cite: 90]。常見於品管不良品抽檢、民調支持人數等情境[cite: 91, 92]。

2. 核心定義與函數

  • 參數空間：試驗次數 $n \in \mathbb{N}$，單次成功機率 $p \in [0, 1]$[cite: 90, 91]
  • 支撐集 (Support)：$x \in \{0, 1, 2, \dots, n\}$[cite: 91]

機率質量函數 (PMF)：

$$p_X(x) = P(X = x) = \binom{n}{x} p^x (1 - p)^{n - x}, \quad x = 0, 1, \dots, n$$

累積分布函數 (CDF)：

$$F_X(x) = P(X \le x) = \sum_{k=0}^{\lfloor x \rfloor} \binom{n}{k} p^k (1 - p)^{n - k}$$

3. 核心統計量摘要

期望值 $E[X]$$np$[cite: 92]
變異數 $\text{Var}(X)$$np(1 - p) = npq$[cite: 92]
動差母函數 (MGF) $M_X(t)$$(1 - p + pe^t)^n, \quad \forall t \in \mathbb{R}$

4. 關鍵性質與定理

  • 變異數上限：因 $0 \le 1 - p \le 1$，二項分布的變異數恆不大於期望值（$\text{Var}(X) \le E[X]$）[cite: 93]。
  • 失敗次數對稱性：若 $X \sim \text{Bin}(n, p)$，則失敗次數 $Y = n - X \sim \text{Bin}(n, 1 - p)$[cite: 93]。
  • 卜瓦松逼近：當 $n$ 極大且 $p$ 極小（經驗法則：$n \ge 100$ 且 $np \le 10$）時，可用 $\text{Poi}(\mu = np)$ 近似[cite: 97]。
  • 常態逼近：當 $np \ge 5$ 且 $n(1 - p) \ge 5$ 時，可用 $N(np, np(1-p))$ 近似（需搭配 $\pm 0.5$ 連續性修正）[cite: 108]。
點擊展開推導：利用指示變數求 $E[X]$ 與 $\text{Var}(X)$

令 $X = X_1 + X_2 + \dots + X_n$，其中 $X_i \stackrel{\text{i.i.d.}}{\sim} \text{Ber}(p)$ 為第 $i$ 次試驗是否成功的指示變數[cite: 92]：

$$E[X_i] = p, \quad \text{Var}(X_i) = E[X_i^2] - (E[X_i])^2 = p - p^2 = p(1 - p)$$

由期望值線性性質與獨立隨機變數變異數可加性得[cite: 92]：

$$E[X] = \sum_{i=1}^n E[X_i] = np, \qquad \text{Var}(X) = \sum_{i=1}^n \text{Var}(X_i) = np(1 - p)$$

常態分布 (Normal Distribution)

標準記號：$X \sim N(\mu, \sigma^2)$（亦稱高斯分布）

1. 直觀意義與應用場景

統計學中最核心的連續型分布，圖形為以平均數 $\mu$ 為中心的左右對稱鐘形曲線[cite: 105]。根據中央極限定理（CLT），大量獨立隨機變數之和在標準化後會趨近於常態分布，因此廣泛用於大樣本推論、自然測量誤差與品質管制[cite: 105, 127]。

2. 核心定義與函數

  • 參數空間：位置參數 $\mu \in \mathbb{R}$，尺度參數 $\sigma^2 > 0$
  • 支撐集 (Support)：$x \in (-\infty, \infty)$[cite: 105]

機率密度函數 (PDF)：

$$f_X(x) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right), \quad -\infty < x < \infty$$

累積分布函數 (CDF)：無初等函數封閉解，透過標準常態分布表 $\Phi(z)$ 查詢：

$$F_X(x) = \Phi\left(\frac{x - \mu}{\sigma}\right) = \int_{-\infty}^{\frac{x-\mu}{\sigma}} \frac{1}{\sqrt{2\pi}} e^{-t^2/2} \, dt$$

3. 核心統計量摘要

期望值 $E[X]$$\mu$
變異數 $\text{Var}(X)$$\sigma^2$
動差母函數 (MGF) $M_X(t)$$\exp\left(\mu t + \frac{1}{2}\sigma^2 t^2\right), \quad \forall t \in \mathbb{R}$

4. 關鍵性質與定理

  • 線性轉換與標準化：若 $X \sim N(\mu, \sigma^2)$，則 $aX + b \sim N(a\mu + b, a^2\sigma^2)$；特別地，$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$[cite: 106]。
  • 經驗法則 (68-95-99.7 Rule)：資料落在 $\mu \pm \sigma$、$\mu \pm 2\sigma$、$\mu \pm 3\sigma$ 內的機率分別約為 $68\%$、$95\%$ 與 $99.7\%$[cite: 42]。
  • 獨立可加性：若 $X_i \stackrel{\text{indep.}}{\sim} N(\mu_i, \sigma_i^2)$，則 $\sum_{i=1}^n X_i \sim N\left(\sum_{i=1}^n \mu_i, \sum_{i=1}^n \sigma_i^2\right)$。
點擊展開推導：常態分布的動差母函數 (MGF)

先求標準常態 $Z \sim N(0, 1)$ 的 MGF，利用指數配方法 $z^2 - 2tz = (z - t)^2 - t^2$：

$$M_Z(t) = \int_{-\infty}^{\infty} e^{tz} \frac{1}{\sqrt{2\pi}} e^{-z^2/2} \, dz = e^{t^2/2} \underbrace{\int_{-\infty}^{\infty} \frac{1}{\sqrt{2\pi}} e^{-(z-t)^2/2} \, dz}_{= 1 \text{（} N(t,1) \text{ 全機率積分）}} = e^{t^2/2}$$

再透過 $X = \mu + \sigma Z$ 的線性轉換得出一般常態分布之 MGF：

$$M_X(t) = E[e^{t(\mu + \sigma Z)}] = e^{\mu t} M_Z(\sigma t) = \exp\left(\mu t + \frac{1}{2}\sigma^2 t^2\right)$$

指數分布 (Exponential Distribution)

標準記號：$X \sim \text{Exp}(\lambda)$

1. 直觀意義與應用場景

與卜瓦松分布（計算單位時間內事件發生「次數」）互為對偶，指數分布描述的是在卜瓦松過程中，「兩次事件之間的時間間隔」或「等待首次事件發生所需的時間」[cite: 110]。常見於零件壽命、顧客進店等待時間、客服下一通來電間隔[cite: 110]。

2. 核心定義與函數

  • 參數空間：發生率參數 $\lambda > 0$（單位時間平均發生次數，注意時間單位須一致）[cite: 110, 112]
  • 支撐集 (Support)：$x \in [0, \infty)$[cite: 110]

機率密度函數 (PDF)：

$$f_X(x) = \lambda e^{-\lambda x}, \quad x \ge 0$$

累積分布函數 (CDF)：

$$F_X(x) = P(X \le x) = 1 - e^{-\lambda x}, \quad x \ge 0 \qquad \text{（右尾生存機率：} P(X > x) = e^{-\lambda x}\text{）}$$

3. 核心統計量摘要

期望值 $E[X]$$\dfrac{1}{\lambda}$[cite: 110]
變異數 $\text{Var}(X)$$\dfrac{1}{\lambda^2}$[cite: 110]
動差母函數 (MGF) $M_X(t)$$\dfrac{\lambda}{\lambda - t}, \quad t < \lambda$

4. 關鍵性質與定理

  • 無記憶性 (Memoryless Property)：唯一具有無記憶性的連續型分布，即 $P(X > a + t \mid X > a) = P(X > t)$[cite: 111]。
  • 與卜瓦松分布的連結：若單位時間事件發生數 $N(t) \sim \text{Poi}(\lambda t)$，則首次發生時間 $W$ 滿足 $P(W > w) = P(N(w) = 0) = e^{-\lambda w}$，即 $W \sim \text{Exp}(\lambda)$[cite: 111]。
點擊展開推導：指數分布的無記憶性證明

由條件機率定義，對任意 $a, t > 0$（因為 $\{X > a + t\} \subset \{X > a\}$）[cite: 111]：

$$P(X > a + t \mid X > a) = \frac{P(\{X > a + t\} \cap \{X > a\})}{P(X > a)} = \frac{P(X > a + t)}{P(X > a)} = \frac{e^{-\lambda(a + t)}}{e^{-\lambda a}} = e^{-\lambda t} = P(X > t)$$
